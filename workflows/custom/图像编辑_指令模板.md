# 图像编辑 · 指令模板（Qwen-Image-Edit 2509）

> 使用位置：无限画布 → 拖入「ComfyUI」节点 → 选「图像编辑 · 指令改图」
> 填法：原图放左侧，编辑指令写在下框；需要参考图时再把参考图放进来。

---

## 一、删除 / 消除

**核心：直接说删什么，不要解释为什么要删。**

| 场景 | 指令写法 |
|---|---|
| 删配饰 | `删除人物耳畔的耳坠，其余保持不变` |
| 删手中物 | `删除她手里拿的花束，手指自然收拢，背景保持不变` |
| 删背景杂物 | `删除画面右侧的灯笼和地上的碎屑，只保留人物与石板路` |
| 删文字水印 | `删除画面左下角的文字和水印，用背景自然填补` |
| 删人物 | `删除画面右侧的行人，该区域用街道背景自然补全` |
| 删服饰件 | `去掉外层那件薄纱披帛，只保留内层长裙` |

**失败时加一句**：`被删除的区域要与周围材质、光影、透视自然衔接，不要留空白或色块。`

## 二、换衣服

### A. 文字描述换装（不需要参考图）

```
将她的衣服换成月白色交领长袍，腰系深青色织金腰带，衣料为哑光真丝，保留原有姿态、发型与光线方向。
```

关键三要素：**颜色 + 款式 + 材质**。缺材质容易出塑料感。

常见组合：
- `换成黑色高领针织衫 + 米色阔腿裤，哑光棉质`
- `换成白色衬衫与深灰西装，挺括面料，保留原有领口层次`
- `换成红色缎面礼服，光泽感，腰线收紧`

### B. 参考图换装（放参考图，效果最接近"试衣"）

```
把图1人物的衣服换成图2中的那套服装，保持图1人物的面部、发型、姿态和光线不变，服装的褶皱与垂坠感要符合图1人物的体态。
```

要点：
- 明确用 **图1 / 图2** 指代，模型才分得清主次
- 必须写 **"保持图1人物的面部、发型、姿态不变"**，否则脸会被参考图带跑
- 补一句 `服装尺寸与图1人物身材匹配，不要照搬图2的体型`

## 三、换场景 / 换背景

### A. 文字描述场景

```
把背景换成雨夜的江南小巷，青石板地面有积水反光，远处挂着手写灯笼，环境光偏冷蓝，人物边缘保留原有的柔和逆光轮廓。
```

必写项：**环境光方向 + 色温**。不写的话人物会像贴上去的。

### B. 参考图换场景

```
把图1的人物放到图2的场景中，人物保持原有姿态、服装与面部特征不变，按图2的光照方向和色温重新给人物打光，人物脚下补充与地面接触的阴影。
```

要点：
- 一定要写 **"按图2的光照方向和色温重新给人物打光"**——这是不"贴图感"的关键
- 一定要写 **接触阴影**，否则人像浮在场景上

## 四、其它高频操作

| 类型 | 指令示例 |
|---|---|
| 改颜色 | `把裙子改成深墨绿色，保留原有褶皱与材质光泽` |
| 改材质 | `把外袍的丝绸换成粗麻，保留版型与褶皱走向` |
| 加物体 | `在她右手边放一只青瓷茶盏，符合现有光影与桌面透视` |
| 改动作 | `把她的手从自然下垂改为轻扶栏杆，手臂角度自然` |
| 改表情 | `把表情改为微微含笑，眼神看向镜头，其余不变` |
| 改文字 | `把招牌上的文字改成"营业中"，字体风格与原图一致` |
| 换风格 | `转为工笔重彩风格，保留构图与人物特征` |
| 换角度 | `改为侧面 45 度视角，保留人物特征与服装细节`（★ 难度高，容易崩，慎用） |
| 局部重绘 | `只修改左手的手指结构，使其五指自然分开，其余画面完全不动` |

## 五、让效果稳定的小技巧

1. **动得少就说"其余保持不变"**。模型默认会重画全图，这句话能锚住不动的地方。
2. **一次只改一件事**。既要换衣又要换景，分两次跑，成功率远高于一次写两句。
3. **要改的部位说得越具体越好**。"把左手食指改直" 优于 "修一下手"。
4. **人物一致性靠"三个不变"**：`面部特征、发型、姿态` 不变 —— 换装换景时必写。
5. **光比什么都重要**。换背景/换场景时，写清光源方向和色温，是"融合"与"贴图"的分界线。
6. **不满意先换种子**（随机种子改成别的数），比改提示词快。
7. **步数**：默认 20 够用；细节崩坏可提到 25–30，代价是更慢。
8. **CFG**：默认 2.5；想更贴合指令提到 3.0–3.5；想更自然降到 2.0。

## 六、参数对照

| 参数 | 默认 | 什么时候调 |
|---|---|---|
| 输出像素量 (MP) | 1.0 | 输出比例自动跟随原图；想要更高清填 1.5–2.0（更慢、更吃显存） |
| 步数 | 20 | 细节崩 → 25~30 |
| CFG | 2.5 | 不听话 → 3.0~3.5；太生硬 → 2.0 |
| 采样偏移 | 3.0 | 一般不动 |
| 随机种子 | 42 | 同一指令多试几个种子，常有惊喜 |

## 七、这套做不到什么（提前说清楚）

- **改不了分辨率上限**：输出像素量是总预算，不是原图分辨率上限；放大会糊。
- **改角度容易崩**：侧面改正面、正面改背面，人物特征容易漂。
- **连续多步编辑会累积劣化**：一次只做一步，做完保存再进下一步。
- **文字类内容**：中文招牌/门牌能改，但长句容易错字，建议单行短语。
